Ceník – úprava cen a délek masáží

Upravte částky a délky, přidejte nebo odeberte variantu. „Uložit na web“ zapíše změny do GitHubu (data.js + ceník v index.html); web se přegeneruje do 1–2 minut.
Přístup k GitHubu (jednorázově)
  1. github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → kucerazdenek78-jpg/Thaimost.
  3. Permissions → Repository permissions → Contents: Read and write. Platnost např. 1 rok.
  4. Token sem vložte. Bez tokenu jde jen „Stáhnout data.js“ a nahrát ručně.
